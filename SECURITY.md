# Security Policy

## Supported Versions

Arnotes is currently pre-1.0. Security fixes are provided for the latest released version only.

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature under **Security > Advisories > Report a vulnerability** in this repository.

Include reproduction steps, affected versions, impact, and any suggested mitigation. Remove credentials, private notes, access tokens, and other personal data from the report.

You should receive an acknowledgement within seven days. Please allow time for a fix and coordinated release before public disclosure.

## Deployment Responsibility

Self-hosters are responsible for using HTTPS, setting strong database and authentication secrets, keeping images and dependencies updated, restricting account registration when appropriate, and maintaining backups.
